# Demo Media Placeholders

This folder is reserved for documentation media.

Expected files:

- `aura-landing.png` - landing screen screenshot
- `aura-intake.png` - intake flow screenshot
- `aura-result.png` - result screen screenshot
- `aura-demo.gif` - short product walkthrough
- `aura-demo.mp4` - longer demo video

Guidelines:

- Do not include real patient data.
- Use synthetic demo sessions only.
- Blur or remove secrets, local tokens, terminal paths, and private machine details.
- Keep media optimized for GitHub display.
